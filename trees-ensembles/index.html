01 / §18.1

Classification and regression trees (CART)

A decision tree recursively divides feature space into regions. Each leaf makes a local prediction. Think of it as a flowchart learned from data, not a hand-written if-statement.

Split

Internal nodes

Ask a question such as x₁ ≤ 5?. A numeric split divides points into two groups; categorical features can be split using equality tests.

Predict

Leaf nodes

Regression: return the average training response in the leaf. Classification: estimate class probabilities using class frequencies.

Geometry

Partitioned space

Axis-aligned splits produce rectangular regions. A regression tree yields a piecewise-constant prediction surface.

Regression tree: f(x) = Σⱼ wⱼ · 𝟙[x ∈ Rⱼ]   |   wⱼ = mean(y in leaf j)
02 / §18.1.2

How does the tree choose a split?

CART grows greedily: try candidate features and thresholds, then choose the split with the lowest weighted child impurity. The optimal overall tree is computationally difficult to find.

What the math says

Gini impurity

Gini(D) = 1 − Σ꜀ p(c)²

Both children are mixed. Impurity is high.

Left 0.50 · Right 0.50 → weighted 0.50

Entropy (alternative)

H(D) = −Σ꜀ p(c) log p(c)

Weighted entropy: 0.693 nats

A good split makes child nodes purer; a perfect split has impurity 0.

Here each child has 10 samples, so the weighted cost is ½ × left impurity + ½ × right impurity. Real CART compares this across candidate splits.

03 / §18.1.3–18.1.5

Why not grow a giant tree?

Deep trees can memorize the training set. A tiny data change may also change an early split, reshaping the entire tree—this is high variance.

Pre-pruning

Stop growing early

Set a maximum depth or require a minimum number of observations before splitting.

Post-pruning

Grow then simplify

Grow a large tree, then merge branches back into parents. More work, but can correct some greedy early decisions.

Missing features

Surrogate splits

Use backup features with similar split behavior when the preferred test feature is missing; categorical missingness may also be a separate value.

Strengths ↔ limitations

StrengthsLimitations
Interpretable, fast, handles mixed inputsIndividual trees may be less accurate
Automatic feature selection; no standardization neededGreedy splitting may miss globally useful patterns
Relatively robust to outliers; missing-value strategiesUnstable: small data changes can cause large tree changes
04 / §18.2

One fragile tree. Many stronger voices.

Ensemble learning combines multiple base predictors. Averaging can reduce variance without changing bias very much—especially when the models' errors are not perfectly correlated.

Regression

Average predictions

ŷ = (1/M) Σₘ fₘ(x)

For example, predictions 6, 8, and 7 combine to give 7.

Classification

Majority vote

ŷ = majority{f₁(x), …, fₘ(x)}

Each classifier casts a vote. This is useful when individual models are better than chance and their mistakes differ.

Why it works

Diversity is essential

The textbook's dramatic voting gains assume independent errors. Identical or highly correlated mistakes reduce the benefit.

Probability of a correct majority (odd M, independent models): P(correct) = Σₖ₌₍ₘ₊₁₎/₂ᴹ C(M,k) θᵏ(1−θ)ᴹ⁻ᵏ

06 / §18.2.1–18.2.2

Beyond a simple average.

Two distinctions from the textbook that are easy to confuse on a quiz.

Stacking

Learn the combination

f(x) = Σₘ wₘ fₘ(x)

Rather than fixed equal weights, learn how much to trust each model. The textbook emphasizes fitting combination weights on separate data to avoid simply favoring the strongest training-set model.

Bayesian model averaging (BMA)

Different interpretation

p(y|x,D) = Σₘ p(m|D) p(y|x,m,D)

BMA uses posterior probabilities of models. Ordinary ensembles learn or choose combination weights as part of a larger predictive model, rather than averaging over a posterior on model identity.

Scope note: Bagging, random forests, and boosting are Sections 18.3–18.5 and are intentionally not taught in this review.

One-screen cheat sheet.

CART

Partition features recursively → assign prediction in each leaf. Regression predicts mean response; classification predicts class frequencies.

Fit a split

Minimize weighted child impurity. Gini = 1 − Σp²; entropy = −Σp log p; regression cost = mean squared error.

Avoid overfit

Limit tree growth or prune. Trees are interpretable but high-variance and sensitive to training perturbations.

Ensemble

Average regression outputs or vote on classification labels. Diversity and low error correlation drive the gain.

Stacking

Learn weights for base predictions using separate data, instead of always averaging equally.

Not BMA

Ensembling creates a combined predictor; BMA weights model-specific predictions by posterior model probability.
