01 / Reconnect the pieces

You already know the tools.

Bayes’ rule is a probability identity. Naive Bayes is a model that uses that identity. MLE is a way to fit the model. These are different jobs, not competing ideas.

ConceptThe question it answersIts job in this lesson
ProbabilityHow likely is an outcome under a model?Give a word’s presence or a class a probability.
LikelihoodWith the observed data fixed, how well do different parameters explain it?Score candidate model parameters using the training data.
MLEWhich parameters maximize that likelihood?Fit Naive Bayes using counts, means, or variances.
Bayes’ ruleHow do I reverse the conditioning direction?Convert p(x | y) and p(y) into p(y | x).
Naive BayesHow can I build a simple classifier?Model features separately within each class, then combine them.
ExpectationWhat is the probability-weighted average?Background tool; not a synonym for likelihood or Bayes’ rule.
EntropyHow uncertain is a distribution?H(Y) = E[−log p(Y)]. It measures uncertainty; it is not the classifier.
Train / learn the parameters

Known labels → class statistics

Of 100 training emails, 20 are spam. Of those 20, 16 contain “free.”

p(Spam) = 20/100 = 0.2
p(free present | Spam) = 16/20 = 0.8

These are maximum-likelihood estimates for a class frequency and a Bernoulli feature probability.

Predict / infer the label

New features → class probability

The new email’s label is unknown. Use the learned probabilities to ask which class best explains its features.

p(Spam | words)
∝ p(Spam) × p(words | Spam)

The ∝ symbol means “proportional to.” Normalize the class scores so they sum to 1.

Why does “Bayes” show up twice?

Ordinary Naive Bayes can fit its parameters using MLE and still use Bayes’ rule to predict a label. Bayesian Naive Bayes additionally puts priors on the parameters and updates their distributions using the data. A class prior p(y) is different from a prior over a parameter p(θ).

02 / Section 9.3

A classifier built from
small pieces of evidence.

The Naive Bayes assumption: features are conditionally independent given the class. It does not say that the features are independent overall.

p(x | y = c) = ∏d=1…D p(xd | y = c)
score(c) = p(y = c) ∏d p(xd | y = c)
p(y = c | x) = score(c) / ∑c′ score(c′)

Read ∏ as “multiply over the features”; read ∑ as “add over the classes.” Here x is the feature vector, y is the label, c is a possible class, and D is the number of features.

01 · FIT

Count how often each class and feature value occurs.

02 · SCORE

Multiply the class prior by each observed feature’s likelihood.

03 · NORMALIZE

Divide each score by the sum of all class scores.

Why “naive”? Words such as “free” and “winner” may remain related even among spam emails. The model simplifies that relationship. It can still classify well, but correlated evidence can make its probabilities overconfident.

Absent ≠ unobserved

In Bernoulli Naive Bayes, an absent word contributes 1 − θ. An unobserved feature is marginalized out; under Naive Bayes, its factor becomes 1.

Ignoring missing features assumes the missingness mechanism contributes no additional information relevant to the prediction.

Unseen ≠ impossible

If a word never appeared in 20 spam emails, its MLE is zero. Add-one smoothing gives both binary outcomes one pseudo-count:

p(word present | Spam) = (0 + 1)/(20 + 2)

For K categorical outcomes: (count + 1)/(class count + K). This is a posterior predictive probability under a uniform Dirichlet prior, not generally the MAP estimate.

9.3.1 / Which distribution goes with which feature?

Binary → Bernoulli: word present/absent. Categorical → categorical: a feature with K possible values. Real-valued → Gaussian: estimate a mean and variance for each feature within each class. Gaussian Naive Bayes corresponds to Gaussian discriminant analysis with diagonal covariance matrices; these matrices need not be shared across classes.

9.3.2 / What are the fitted parameters?

Class prior: π̂c = Nc/N. Categorical feature probability: θ̂dck = Ndck/Nc. For a real-valued feature, estimate the within-class sample mean and the variance using denominator Nc for MLE. In larger problems, compute log scores: log πc + ∑d log p(xd | c), which avoids multiplying tiny numbers.

9.3.4 / How can Naive Bayes look like logistic regression?

For categorical features in a one-hot representation, taking logs turns products into a sum: log score(c) = log πc + ∑d,k xdk log θdck. Normalizing exponentiated scores is a softmax, just like multinomial logistic regression. But Naive Bayes fits the joint likelihood ∏ p(xₙ,yₙ), while logistic regression fits the conditional likelihood ∏ p(yₙ | xₙ). Same posterior form does not imply the same fitted parameters. Gaussian Naive Bayes with class-specific variances can yield quadratic, rather than linear, log-odds.

03 / Section 9.4

Two routes to
the same kind of answer.

The difference is what is modeled during training. Both routes can output a posterior class probability when asked to classify a new input.

Generative

“What does each class look like?”

Learn the weight distribution of cats and the weight distribution of dogs, plus how common each class is. For a new weight, use Bayes’ rule.

p(x,y) = p(y)p(x | y)
↓ Bayes’ rule
p(y | x)

Examples: Naive Bayes; Gaussian discriminant analysis. Called generative because you could sample a class, then sample an input from that class.

Discriminative

“How does this input predict the label?”

Learn a direct relationship between weight and the probability of being a cat. No separate model of the cats’ or dogs’ weight distributions is required.

p(y | x)
↑ learned directly from
labeled examples

Example: logistic regression. Some other discriminative classifiers learn a decision score rather than a probability distribution.

Do not classify the classifier by its final output. Seeing p(y | x) at prediction time does not tell you whether the model is generative or discriminative. Ask what it learned during training.

Does “generative” here mean ChatGPT or image generation?

Here it means the model specifies a joint distribution p(x,y), from which it can generate class/input pairs. Naive Bayes qualifies even though it is a simple classifier. The term describes the probability model, not how realistic its generated samples look.

Are generative classifiers always more robust?

No. The textbook discusses potential robustness to spurious features and distribution shifts when a generative model captures the right mechanisms. That depends on the model and the data; a generative label alone gives no robustness guarantee.

Cover the answers. Say them out loud.

Bayes’ rule vs. Naive Bayes?

A probability identity vs. a classifier that uses it, with a conditional independence assumption.

What does “naive” assume?

Features are independent conditional on the class. They need not be independent overall.

Prior, likelihood, posterior?

Prior: class probability before the input. Likelihood: how well the class explains the input. Posterior: class probability after the input.

Why add 2 in binary smoothing?

There are two outcomes, present and absent. Adding one count to each adds two to the total.

The key difference in 9.4?

Generative learns p(y)p(x | y); discriminative learns p(y | x) directly. Both can yield p(y | x) at prediction time.

Why can outputs look identical?

Different training objectives can lead to the same posterior form. Naive Bayes with categorical features produces a softmax over linear one-hot feature scores.

05 / One-screen recap

Keep the jobs separate.

The rule

Posterior ∝ prior × likelihood

Bayes’ rule reverses the conditioning direction. It is not itself a model or a training method.

The model

Naive Bayes = class prior × feature factors

Fit probabilities by class, multiply observed-feature factors, then normalize.

The two routes

Generative: learn class-specific input distributions, then apply Bayes. Discriminative: learn the label probability given input directly.

The three traps

A score is not yet a posterior. Unseen is not impossible. An absent feature is not a missing feature.
