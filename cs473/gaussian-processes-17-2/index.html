01 / What is a Gaussian Process?

A GP puts a probability distribution over functions. For any finite collection of inputs, their function values have a joint Gaussian distribution. A kernel tells us which inputs should have correlated outputs.

17.2.1 · Noise-free observations

yᵢ = f(xᵢ)

Training observations are exact. At an observed input, the posterior matches its training value, with zero theoretical latent uncertainty (for a nonsingular kernel).

The curve interpolates training points.

17.2.2 · Noisy observations

yᵢ = f(xᵢ) + εᵢ εᵢ ~ Normal(0, σᵧ²)

Measurements contain independent Gaussian noise. We infer the underlying smooth latent function f, which need not pass exactly through each measurement.

Add σᵧ²I to training covariance.

Why do we care? Linear regression fits a particular functional shape. A GP instead uses correlations among function values to make probabilistic predictions, including a prediction interval.

02 / The entire algorithm in four matrices

X: N × D training inputs y: N × 1 observed targets X*: M × D test inputs K = k(X, X) → N × N training covariance Kcross= k(X, X*) → N × M train-test covariance Ktest = k(X*, X*) → M × M test covariance A = K + σᵧ² I → N × N noisy training covariance

Here k is a positive-definite kernel and m is the GP prior mean function. Use σᵧ² = 0 for 17.2.1, and positive σᵧ² for 17.2.2.

Posterior mean

μ* = m(X*) + Kcrossᵀ A⁻¹(y − m(X))

The prior mean plus a correction informed by observed data and kernel similarities.

Posterior covariance

Σ* = Ktest − Kcrossᵀ A⁻¹ Kcross

Start with prior uncertainty; subtract what you learned from the data. The diagonal entries are latent variances.

Example kernel: squared exponential (RBF)

k(x, x') = σf² · exp(−||x − x'||² / (2ℓ²))

Length scale ℓ: larger ℓ means smoother, longer-range correlation. Signal standard deviation σf: controls prior function amplitude. Noise σy: controls how closely the posterior follows measurements. The kernel is background from §17.1, used here for implementation.

04 / Implement it for the lab

Step-by-step

1
Build K, Kcross, and Ktest

Use the same kernel and hyperparameters for all pairs.

2
Add observation-noise variance on K's diagonal

σy is a standard deviation; the matrix term is σy², not σy. For noise-free data use zero.

3
Solve a linear system, not an explicit inverse

Use Cholesky or np.linalg.solve. Add very small jitter for numerical stability.

4
Compute the posterior and credible band

Get the posterior mean, covariance, and sqrt of nonnegative diagonal covariance values.

Working NumPy reference implementation

import numpy as np

def rbf_kernel(X1, X2, lengthscale=1.0, signal_std=1.0):
    X1 = np.atleast_2d(np.asarray(X1, dtype=float))
    X2 = np.atleast_2d(np.asarray(X2, dtype=float))
    sqdist = np.sum((X1[:, None, :] - X2[None, :, :])**2, axis=2)
    return signal_std**2 * np.exp(-sqdist / (2 * lengthscale**2))

def gp_predict(X_train, y_train, X_test,
               lengthscale=1.0, signal_std=1.0,
               noise_std=0.0, jitter=1e-8):
    X_train = np.atleast_2d(np.asarray(X_train, dtype=float))
    X_test = np.atleast_2d(np.asarray(X_test, dtype=float))
    y_train = np.asarray(y_train, dtype=float).reshape(-1)

    K = rbf_kernel(X_train, X_train, lengthscale, signal_std)
    Ks = rbf_kernel(X_train, X_test, lengthscale, signal_std)
    Kss = rbf_kernel(X_test, X_test, lengthscale, signal_std)

    A = K + (noise_std**2 + jitter) * np.eye(len(X_train))
    L = np.linalg.cholesky(A)
    alpha = np.linalg.solve(L.T, np.linalg.solve(L, y_train))
    mean = Ks.T @ alpha

    v = np.linalg.solve(L, Ks)
    covariance = Kss - v.T @ v
    covariance = (covariance + covariance.T) / 2
    std = np.sqrt(np.maximum(np.diag(covariance), 0.0))
    return mean, covariance, std

# Data shapes: X_train (N, D), y_train (N,), X_test (M, D)
X_train = np.array([[-2.], [0.], [2.]])
y_train = np.array([-0.9, 0.2, 0.8])
X_test = np.linspace(-4, 4, 200).reshape(-1, 1)

# Section 17.2.1: exact observations
mean_exact, cov_exact, std_exact = gp_predict(
    X_train, y_train, X_test, noise_std=0.0)

# Section 17.2.2: noisy observations
mean_noisy, cov_noisy, std_noisy = gp_predict(
    X_train, y_train, X_test, noise_std=0.4)

# Latent credible band at test points:
lower = mean_noisy - 2 * std_noisy
upper = mean_noisy + 2 * std_noisy

# For future noisy observations, use:
pred_observation_std = np.sqrt(std_noisy**2 + 0.4**2)
Scope note: The implementation uses a zero prior mean (m(x)=0) and an RBF kernel for clarity. Murphy's §17.2.1–2 also gives the more general nonzero-mean expressions. Cholesky stabilization is further discussed in §17.2.5.

05 / Debug checklist

Expected in noise-free GP

✓ Prediction at training x matches y (up to jitter and rounding).

✓ Latent variance at observed inputs approaches zero.

✓ Uncertainty generally grows in data-sparse regions.

Expected in noisy GP

✓ Training observations need not lie on posterior mean.

✓ Increasing σy generally weakens trust in observations.

✓ Do not confuse latent f* variance with noisy y* variance.

Common errors

BugCorrect approach
Adding σy rather than σy²Use noise variance on diagonal
Adding noise to Ktest for latent predictionsKeep Ktest noise-free for f*
Inverting K explicitlyCholesky / linear solve
Dimension mismatchKcross must be N × M
Negative variance due to roundingClamp diagonal near zero when taking sqrt
