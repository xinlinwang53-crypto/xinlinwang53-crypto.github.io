Every new tree
fixes the last.

A random forest averages trees trained largely independently. Gradient boosting instead builds an additive model sequentially: the next weak learner approximates the direction that reduces the current loss.

01

Start with a guess

Initialize predictions with a constant that minimizes the training loss. For squared error, this is the mean target.

f₀(x) = arg minc Σᵢ ℓ(yᵢ,c)
02

Calculate pseudo-residuals

Take the negative gradient of the loss with respect to each current prediction. It tells us the direction to move.

rᵢₘ = −∂ℓ(yᵢ,f(xᵢ))/∂f(xᵢ)
03

Fit and add a small tree

Fit a regression tree to those pseudo-residuals, then add its predictions with shrinkage (learning rate ν).

fₘ(x) = fₘ₋₁(x) + νFₘ(x)

One algorithm.
Many losses.

The negative gradient depends on the loss function. That is why gradient boosting extends beyond ordinary residual fitting.

Squared error · regression

With ℓ(y,f) = ½(y − f)², the negative gradient is exactly the ordinary residual.

−∂ℓ/∂f = y − f

Next tree learns what the prediction missed.

Binary log loss · classification

For a logit-score parameterization, negative gradients involve the difference between the observed label and current predicted probability.

−∂ℓ/∂score = y − p

Exact scaling depends on the chosen logit convention. In multiclass problems, class-specific residuals take the form 𝟙(y=c) − p(c|x), with probabilities combined by softmax.

Why use trees?

In gradient tree boosting, each weak learner partitions feature space into leaf regions Rⱼ. The tree gives each region a constant correction wⱼ. In the general formulation, leaf values can be refined to minimize the original loss within the region, rather than simply keeping the values from fitting pseudo-residuals.

Fₘ(x) = Σⱼ wⱼ · 𝟙(x ∈ Rⱼ)

Regularization levers: smaller learning rate ν, fewer rounds, shallower trees, and stochastic subsampling. See §18.5.5 and §18.5.5.1.

What importance does not say

A high importance score says the ensemble frequently gained predictive fit from splitting on that feature. It does not by itself tell you whether higher feature values increase or decrease the prediction.

It also does not prove causality. Correlated predictors can share or redistribute importance, and gain-based measures can favor features with more potential split points.

Average over the other features

PDₖ(z) = (1/N) Σᵢ f(z, xᵢ,₋ₖ)

For every candidate value z, replace feature k with z in all N examples. Ask the fitted model to predict each modified example, then average those predictions.

For two selected features, we can plot a 2D surface to explore model interactions.

60-second
cheat sheet.

If you remember only four ideas, remember these.

1. Pseudo-residuals

They are negative loss gradients evaluated at the current predictions—not always y − f.

2. Sequential learning

Fit the next tree to correct the current ensemble; add it with shrinkage.

3. Feature importance

Ranks what the model uses, often by total split gain. Importance is not direction or causation.

4. Partial dependence

Average model outputs across a dataset after varying one or two chosen features.
