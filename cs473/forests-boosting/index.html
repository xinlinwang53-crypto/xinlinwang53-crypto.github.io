The big picture

Two different ways to build an ensemble

PARALLEL / DIVERSITY

Bagging → Random Forest

Train many different trees on bootstrap samples. A random forest adds random feature selection at each split, reducing correlation among trees.

predict = average / majority vote

Main intuition: reduce variance through averaging; independent training permits parallelism.

SEQUENTIAL / CORRECTION

Boosting → Strong Additive Model

Fit one weak learner, examine what the current model gets wrong, and add a learner that improves the combined prediction.

fₘ(x) = fₘ₋₁(x) + βₘFₘ(x)

Main intuition: sequential correction often reduces bias, but can be sensitive to noise and overfitting.

Key distinction: random forests make trees different from each other; boosting makes later trees depend on the mistakes of earlier trees.
§ 18.4

Random Forests

Bootstrap observations are only half the randomness. At every node, consider a randomly selected subset of features rather than all D input dimensions.

Training recipe

01. Draw a bootstrap sample of training rows.
02. At each tree node, randomly choose candidate features Sᵢ ⊂ {1,…,D}.
03. Find the best split using only features in Sᵢ.
04. Repeat for many trees; average predictions or vote.

Why does random feature selection help?

If a single strong feature dominates, ordinary bagged trees may keep splitting on it and become highly correlated. Restricting candidate features gives other predictors a chance.

Murphy's spam-email example has 57 numerical features. Figure 18.5 compares test error versus ensemble size and illustrates the benefit of decorrelating trees. Actual performance depends on the dataset and hyperparameters.

§ 18.5.1

Forward Stagewise Additive Modeling

We build a sum of learned functions, one component at a time. Earlier components are frozen; only the new component and its coefficient are optimized.

(βₘ, θₘ) = argminβ,θ Σᵢ ℓ(yᵢ, fₘ₋₁(xᵢ) + βF(xᵢ;θ))
fₘ(x) = fₘ₋₁(x) + βₘFₘ(x)
fₘ₋₁

Current ensemble

What the model already predicts before stage m.

Fₘ

New weak learner

A fresh function selected to improve the current loss.

βₘ

Step strength

Controls how much the new learner changes the ensemble.

A “weak learner” need not be a tree in the general additive-model formulation. The precise stagewise optimization changes with the loss function.

§ 18.5.3 · Interactive

Exponential Loss & AdaBoost

Binary labels are represented by y ∈ {−1,+1}. Errors on points with large negative margins are penalized exponentially, and misclassified examples receive larger weights in the next round.

Core equations

ℓ(y, f(x)) = exp(−yf(x))
errₘ = Σᵢ wᵢ 𝟙[yᵢ ≠ Fₘ(xᵢ)] / Σᵢ wᵢ
βₘ = ½ ln((1 − errₘ)/errₘ)
wᵢ ← wᵢ exp(−βₘyᵢFₘ(xᵢ))

Equivalent normalized weight ratios multiply the misclassified points by exp(2βₘ) relative to correctly classified points.

§ 18.5.4

LogitBoost: a different loss

AdaBoost's exponential loss can be disproportionately affected by mislabels and outliers. LogitBoost uses the logistic log-loss, which also connects the additive score directly to calibrated-probability modeling (though actual calibration is not guaranteed).

Loss comparison

Exponential exp(−margin)   Log loss ln(1 + exp(−2 margin))

x-axis: margin y f(x). Both losses decrease when the correct-class margin grows. On a badly misclassified example, exponential loss grows faster.

From score to probability

P(y=+1 | x) = 1 / (1 + exp(−2f(x)))
P(y=+1 | x) = 50.0%

Algorithm intuition

LogitBoost uses an IRLS / Newton-style update: compute working responses and weights based on the current probabilities, then fit a weighted least-squares weak learner.

Algorithm 18.2, in words

1. Initialize probabilities πᵢ = 0.5 and ensemble score f(x) = 0.
2. Compute working response zᵢ = (yᵢ* − πᵢ)/(πᵢ(1−πᵢ)) for yᵢ* ∈ {0,1}.
3. Compute weights wᵢ = πᵢ(1−πᵢ), and fit Fₘ to zᵢ using weighted least squares.
4. Update f ← f + ½Fₘ; update πᵢ = sigmoid(2f(xᵢ)); repeat.

Notation note: the book uses ±1 labels for the margin formula and 0/1 labels (y*) for the working-response update.
