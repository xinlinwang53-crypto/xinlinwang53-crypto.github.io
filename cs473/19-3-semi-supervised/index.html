00 / Context

Learning with fewer labels

Supervised learning uses true labels (x, y). Semi-supervised learning combines a small set of labeled examples with a much larger set of unlabeled examples. The trick is finding information in the unlabeled inputs.

19.3.4

Nearby examples agree.

Build a graph where stronger edges connect more similar datapoints. Spread known labels through the graph.

19.3.5

Altered examples agree.

Apply label-preserving perturbations. A reliable model should make similar predictions before and after.

01 / Label propagation on graphs

Let labels spread through connections.

Manifold assumption: similar datapoints likely share labels. Each node represents a data example; nonnegative edge weights express similarity. Known nodes supply ground truth; unknown nodes receive label distributions.

Transition matrix (19.26)

Tij = wij / Σk wkj

Tij is the normalized probability of propagating the label of node j to node i. Y has one row per example and one column per class.

Y ← T Y

Algorithm, step by step

1. Build similarity graph and transition matrix T.
2. Update soft labels with Y ← TY.
3. Normalize each row of Y to sum to 1.
4. Reset known labeled rows to their one-hot truth.
5. Repeat until Y changes very little; take argmax labels.

Exam trap: Label propagation is typically transductive (predict labels of this fixed unlabeled set). You can train a separate inductive classifier afterward. Results depend strongly on how similarity is defined.
02 / Consistency regularization

Same example. Stable prediction.

A small rotation, brightness change, or noise should not change an image's underlying class. We can compare the model's predictions without knowing its true label. Model stochasticity like dropout can also be used.

Supervised term

LS = −Σi log pθ(yi|xi)

Use correct labels to teach the model the task.

Unlabeled term

LU = Σj ‖pθ(y|xj)−pθ(y|x′j)‖2

Compare original prediction to its transformed prediction x′ sampled from q(x′|x).

Combined objective (19.27)

L(θ) = LS + λ LU

λ determines the importance of unlabeled consistency. Start near λ=0 and increase gradually: a poor initial model may otherwise reinforce its incorrect predictions (confirmation bias). Usually the unperturbed prediction is treated as fixed while differentiating.

Augmentation

Label preserving is essential.

Small rotations, brightness changes, random noise or strong augmentations can work only if the true label remains unchanged.

Virtual adversarial training (VAT)

Find the difficult perturbation.

VAT searches for a small perturbation that maximally changes the prediction using KL divergence, then trains the model to resist that change.

δ ← ∇δ DKL(p(y|x) || p(y|x+δ)) |δ=ξd  (19.28)
x′ = x + ε δ / ‖δ‖2  (19.29)
Figure 19.11: Squared error can saturate and have near-zero gradients for confident predictions, even when the two outputs disagree. KL divergence may grow without bound for an increasingly confident wrong prediction; its scale is comparable to supervised cross-entropy.

04 / Last-minute review

The one-minute cheat sheet

Label propagation

Assumption: similar nodes share labels.
Recipe: graph → T → Y ← TY → normalize rows → reset known labels → repeat.
Risk: bad similarity, wrong spread.
Type: transductive by default.

Consistency regularization

Assumption: label-preserving perturbations should not alter predictions much.
Objective: supervised loss + λ × consistency loss.
Risk: confirmation bias, non-label-preserving transforms.
VAT: adversarially chosen tiny perturbation.
