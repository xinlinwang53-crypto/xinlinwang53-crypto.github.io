01 / Understand the picture

High-dimensional data can have a low-dimensional shape.

20.4.1 · MANIFOLD

Locally flat, globally curved

Imagine the surface of Earth. It curves in 3D, but if you zoom in, a small patch looks like a flat 2D plane. A manifold behaves similarly.

20.4.2 · HYPOTHESIS

Real data is constrained

A 64×57 image has 3,648 pixels, but valid pictures of a handwritten digit vary along far fewer meaningful factors, such as rotation and shape.

20.4.3 · GOAL

Uncover hidden coordinates

Find a compact representation that retains useful structure. This helps visualization, discovery, and sometimes downstream prediction.

One-sentence takeaway: The number of measured features (ambient dimension) can be much bigger than the number of independent factors needed to describe the data (intrinsic dimension).

The Swiss roll intuition

A rolled sheet has only two degrees of freedom, even though its points live in a three-dimensional space. A straight-line shortcut through the roll can make two distant points appear close.

Manifold learning tries to respect the sheet's underlying structure, not just its appearance in the surrounding space.

02 / The algorithm landscape

Different algorithms preserve different things.

The assigned reading asks for a sense of the space of possible algorithms. The question to ask is not “How do I derive it?” but “What relationship is it trying to keep?”

DISTANCE / GLOBAL

Classical MDS

Start with pairwise dissimilarities; place points in fewer dimensions so those relationships remain similar. Classical MDS using Euclidean distances is connected to PCA.

Remember: preserve global pairwise geometry.

DISTANCE / GRAPH

Isomap

Build a graph of nearby points, approximate distances along the manifold with graph shortest paths, then use MDS to embed them.

Remember: “distance along the roll,” not through it.

SIMILARITY / NONLINEAR

Kernel PCA

Use a nonlinear similarity (kernel), then apply a PCA-style technique in the implied feature space.

Remember: nonlinear extension of PCA.

LOCAL RECONSTRUCTION

LLE

Represent each point using weighted combinations of neighbors. Find low-dimensional points that preserve those local reconstruction relationships.

Remember: keep how neighbors reconstruct each other.

LOCAL GRAPH

Laplacian Eigenmaps

Connect neighboring points in a graph and encourage nearby connected points to stay close in the embedding.

Remember: preserve neighborhood connections.

VISUALIZATION / PROBABILITIES

t-SNE

Convert similarities into neighbor probabilities and seek a 2D or 3D layout with similar local relationships. Good for visual exploration, but global distances and cluster sizes can be misleading.

Remember: local neighborhoods, especially for visualization.

OPTIONAL FAMILY

Maximum Variance Unfolding

Keep local distances while spreading out the embedding as much as possible. It is another way to unfold curved data.

Remember: local distances + maximum spread.

COMPARISON FROM CH. 20.3

Autoencoder

A neural network learns an encoder that maps an input to a compressed representation and often a decoder that reconstructs it. Unlike most methods above, it can apply its learned encoder to new points.

Remember: learns a reusable mapping.
