Density,
revealed.

Where do data tend to live? Put a small bump on every observation. Add the bumps. You have a probability density—without assuming one global bell curve.

中文直觉：每个数据点放一个“小山包”，叠起来再取平均。点越密集，曲线通常越高。

01 / The big picture

Remember points, estimate shape.

Density estimation

Estimate p(x): how concentrated observations are near x. Labels are unnecessary. Density is not the probability of one exact continuous value; probability is area over an interval.

Nonparametric

The representation grows with the dataset. KDE stores the observations instead of fitting a fixed number of mixture centers. It still has a smoothing hyperparameter h.

A generative model

You can evaluate p̂(x). To sample Gaussian KDE, choose a training point uniformly, then add Gaussian noise with standard deviation h in each dimension.

02 / §16.3.1–16.3.2

One formula, three operations.

Kh(u) = (1/h)K(u/h)
p̂(x) = (1/N) ∑n=1…N Kh(x − xn)

1. Shift

x − xₙ places a kernel at each observed xₙ. A nearby point usually contributes more than a distant one.

2. Scale

h > 0 controls width. The factor 1/h preserves area when the bump widens. In D dimensions the normalization is 1/hᴰ.

3. Average

Divide the sum by N. Every normalized bump has area 1, so their average also has total area 1.

A density kernel is nonnegative, integrates to 1, and is symmetric around zero. With a finite first moment, symmetry gives mean zero; shifting it to xₙ gives mean xₙ. Here “kernel” means a density kernel, not automatically a Mercer kernel from Chapter 17.

Gaussianexp(−u²/2) / √(2π)Smooth; nonzero at every finite distance

For a boxcar kernel, p̂(x) = count{|x − xₙ| ≤ h}/(2Nh). Here h is the half-width, so the full window width is 2h.

Connection to your GMM work: Gaussian KDE is an equal-weight Gaussian mixture with N components, one mean fixed at each observation, and covariance h²I. You do not run EM to learn these means.
03 / Interactive intuition

Make the bumps too small.
Then too big.

Six fixed observations: 1, 1.6, 2.2, 5.5, 6.2, 7. Query x = 4 lies between two groups.

Mint: KDE · faint orange: each kernel divided by N · white ticks: observations · dashed line: query x = 4. Vertical scale stays fixed.

Small h → flexible, spiky

Low smoothing bias but high sampling variance. You may mistake random sample details for meaningful structure.

Large h → smooth, broad

Lower variance but higher smoothing bias. Real modes can merge or disappear. Bandwidth often matters more than kernel shape.

04 / §16.3.3

Choose a bandwidth, not a story.

Under a one-dimensional Gaussian reference distribution with a Gaussian kernel, the textbook gives:

h = σ [4/(3N)]1/5 ≈ 1.06 σ N−1/5
MAD = median(|x − median(x)|)
σ̂ = 1.4826 × MAD

Example: N = 100 and σ̂ = 2 gives h ≈ 0.84. More data allow narrower bumps. This is a reference rule under assumptions, not a universal optimum; a zero MAD needs a fallback scale or positive bandwidth.

The section also suggests estimating hd separately by dimension and taking their geometric mean, h = (∏dhd)1/D.

Practical extension: held-out likelihood or cross-validation can help tune h. Rescale features when units differ. High-dimensional neighborhoods become sparse, making KDE data-hungry.

Why KDE is convenient

No need to choose the number of clusters or optimize centers. It can represent multiple modes directly.

What it costs

Store all N observations: O(ND) memory. A direct density evaluation costs O(ND) per query. Compact-support kernels can support faster neighborhood-based evaluation.

05 / §16.3.4

KNN voting comes from Bayes.

Instead of fixing a window width, grow a neighborhood around query x until it contains K points. Its volume is V(x). Let Nc be all class-c points in the dataset and Nc(x) the class-c points inside this neighborhood.

p̂(x | y=c) = Nc(x) / [Nc V(x)]
p̂(y=c) = Nc/N
p̂(y=c | x) = Nc(x) / K

Bayes multiplies the first two expressions, giving Nc(x)/[NV(x)]. Normalizing across classes cancels the shared N and V(x). The remaining denominator is K.

Example

Among the 5 nearest neighbors, 3 are blue and 2 orange. Estimated posterior: blue = 3/5, orange = 2/5. Predict blue. This derivation uses the empirical class priors Nc/N.

Memory hook: fixed-bandwidth KDE fixes the window size and counts points; KNN fixes the point count and adapts the window size.

06 / §16.3.5, including all three subsections

From nearby points
to nearby answers.

Regression estimates E[y|x]. A product-kernel estimate of the joint distribution is p̂(x,y) = (1/N)∑ Kh(x−xₙ)Kh(y−yₙ). Integrating over y yields the Nadaraya–Watson estimator:

wₙ(x) = Kh(x−xₙ) / ∑ⱼ Kh(x−xⱼ)
μ̂(x) = ∑ₙ wₙ(x)yₙ,   ∑ₙ wₙ(x) = 1

Think “distance-weighted average of observed outputs.” If raw similarities are 1, 2, 1 and outputs are 10, 20, 30, the normalized weights are ¼, ½, ¼ and the prediction is 20. With compact-support kernels, prediction is undefined if no point receives positive weight.

Predictive variance · §16.3.5.2

Var[y|x] = σ² + ∑ₙ wₙ(x)yₙ² − μ̂(x)²

For a Gaussian response kernel with variance σ²: uncertainty equals the within-kernel spread plus the weighted spread of neighboring outputs. σ² here belongs to the response kernel; it need not equal the input bandwidth squared.

Local linear fit · §16.3.5.3

β̂(x) = arg minβ ∑ₙ Kh(x−xₙ)[yₙ−βᵀφ(xₙ)]²
μ̂(x) = β̂(x)ᵀφ(x)

With φ(t) = [1,t], fit a different locally weighted line at each query. Nearby samples matter more. This is the local linear idea behind LOWESS/LOESS; it can handle local trends better than a constant average.

A notation trap in the textbook

Equation 16.46 removes normalization, producing an unnormalized kernel sum. That does not generally preserve the scale of the Nadaraya–Watson prediction. Equation 16.47 prints μ(x) as a minimum loss; for implementation, minimize to obtain β̂(x), then evaluate the fitted line at x, as shown above.

A minimal NumPy implementation (1D, Gaussian)

import numpy as np

def kde(x_query, samples, h):
    if h <= 0:
        raise ValueError("h must be positive")
    u = (np.asarray(x_query)[..., None]
         - np.asarray(samples)) / h
    return np.mean(np.exp(-0.5*u**2), axis=-1) / (
        h * np.sqrt(2*np.pi))

def kernel_regression(x_query, x_train, y_train, h):
    if h <= 0:
        raise ValueError("h must be positive")
    z = -0.5*((np.asarray(x_train)-x_query)/h)**2
    a = np.exp(z - z.max())  # stable normalization
    w = a / a.sum()
    return w @ np.asarray(y_train)
Assumes finite data, nonempty samples, and matching x/y training lengths.
07 / Active recall

Explain it before you expand it.

Why divide by h and by N?

1/h preserves the area of each one-dimensional kernel after changing width. 1/N averages N unit-area kernels, keeping the final integral equal to one.

Can a density be larger than 1?

Yes. Height is density; probability is area. A narrow density can exceed 1 while still integrating to 1.

What happens as Gaussian KDE h approaches zero?

Each bump becomes extremely narrow and tall. The estimate becomes concentrated near observations and approaches the empirical point-mass distribution in a limiting sense; it does not become a useful smooth population estimate.

How does KDE differ from a fitted GMM?

KDE uses a fixed center at every sample and equal mixture weights. A typical fitted GMM learns a chosen number of means, covariances and weights, often using EM.

What is the denominator in KDE versus kernel regression?

KDE averages normalized density bumps using N. Nadaraya–Watson divides by the sum of input similarities at the query so the output weights sum to one.

What does predictive variance add beyond the predicted mean?

It describes conditional output spread under the estimated model: Gaussian response-kernel variance plus disagreement among locally weighted target values.
