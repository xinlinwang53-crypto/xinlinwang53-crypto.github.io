01 · The intuition

Learning with a hidden variable.

EM is useful when the model would be easy to fit if only you knew some missing or latent variable—such as which cluster generated each data point.

1

Start with a rough model

Choose initial parameters. They do not need to be perfect; they just need to give the loop somewhere to begin.

θ⁽⁰⁾ = initial guess
2

Softly fill in what is hidden

Instead of forcing one label, calculate a probability for every plausible hidden assignment.

p(z | x, θ⁽ᵗ⁾)
3

Refit, then repeat

Treat those probabilities as weighted evidence, update the parameters, and loop until improvement is tiny.

θ⁽ᵗ⁺¹⁾ ← arg max Q
02 · The engine

Two steps. One climb.

Each round does not decrease the observed-data likelihood. EM climbs toward a local optimum, though not necessarily the best global one.

EXPECTATION

E-step

Freeze the parameters. Use the current model to compute the posterior distribution over hidden variables—often called responsibilities.

Q(θ | θᵗ) = Ez|x,θᵗ[log p(x,z | θ)]
E
MAXIMIZATION

M-step

Freeze the responsibilities. Choose parameters that maximize the expected complete-data log-likelihood.

θᵗ⁺¹ = arg maxθ Q(θ | θᵗ)
M

05 · Keep this

The one-screen cheat sheet.

When to use EM

Likelihood-based model + latent or missing variables + conditional computations that make alternating updates manageable.

Core loop

Initialize θ → E-step: infer p(z|x,θ) → M-step: maximize expected complete log-likelihood → test convergence.

What EM guarantees

The observed-data likelihood will not decrease after a complete iteration (under exact updates).

What EM does not guarantee

A global optimum, a unique solution, fast convergence, or immunity to poor initialization and degenerate solutions.

Practical habits

Try multiple starts, monitor log-likelihood, set tolerance + max iterations, and regularize tiny variances.

Memory hook

E = explain the hidden assignments. M = maximize the model fit.
