01 / Section 17.3.5

Score ≠ probability.

An SVM produces sign(f(x)), and its raw margin score is not automatically a calibrated probability. Platt scaling fits a sigmoid on a separate validation set:

P(y = 1 | x) = σ(a f(x) + b),   σ(z) = 1 / (1 + e−z)

Try the probability converter

Illustration with a = 1 and b = 0. Actual Platt scaling learns both parameters.

Estimated class-1 probability: 73.1%

What to remember

• A positive score means class +1, not a specific probability.
• Fit sigmoid parameters on held-out data, not the original SVM training set.
• Calibration is not guaranteed: SVM training never required f(x) to equal log odds.

A bigger margin ≠ a guaranteed probability

Textbook example: both an RVM and SVM can recover the decision boundary, yet the SVM’s derived log-odds can be badly calibrated (Figure 17.15).

02 / Section 17.3.6

Hinge loss or log loss?

Let m = y f(x) be the signed margin, with labels y ∈ {−1,+1}. Both losses are convex surrogates for hard-to-optimize 0–1 classification loss.

SVM · Hinge loss

Lhinge = max(0, 1 − m)

Exactly zero once m ≥ 1. Correct classifications inside the margin still incur loss. This zero region helps produce sparse SVM solutions.

Logistic regression · Log loss

Llog = log(1 + e−m)

Smooth, never exactly zero for finite m. Continues rewarding increased confidence in the correct class.

Inspect the two losses

Hinge loss: 0.500   ·   Log loss: 0.474

03 / Section 17.3.7

Binary models, multiple classes.

One-vs-rest · OVR

One class against everyone

For K classes, train K binary classifiers. Pick the highest score, but scores may be incomparable, the binary problems can be imbalanced, and ambiguous regions can arise.

Number of models = K

For cat / dog / bird: cat vs rest, dog vs rest, bird vs rest.

One-vs-one · OVO

Every class pair competes

Train a classifier for each pair. Each pair votes; choose the most votes. Ties or ambiguous regions can arise; model count grows quadratically.

Number of models = K(K − 1) / 2

For cat / dog / bird: cat–dog, cat–bird, dog–bird.

Tradeoff

OVO trains more models; each model sees only two classes.

04 / Section 17.3.8

C and γ must be tuned together.

C penalizes margin violations. For the RBF kernel, γ controls kernel width. Their interaction matters; textbook Figure 17.17 illustrates this on the two-moons dataset.

SVM: min ½ ||w||² + C Σ ξᵢ   ·   RBF kernel: K(x,x′) = exp(−γ ||x−x′||²)

Interactive intuition

C = 1   ·   γ = 1

Conceptual interpretation only; this lab does not train an SVM or report accuracy.

Rules worth memorizing

Small C → stronger regularization; tolerate more margin violations.
Large C → weaker regularization; penalize violations more.
Large γ → narrow RBF kernels, local influence, potentially complex boundaries.
Small γ → wide kernels, smoother influence.

Select (C, γ) using cross-validation

Murphy cites the libsvm recommendation of searching a 2D grid. Do not tune C in isolation.

05 / Sections 17.4–17.4.2

Use fewer exemplars. Predict faster.

Kernel models can represent an input through similarities to training examples. If many coefficients are zero, we need fewer comparisons at prediction time.

φ(x) = [K(x,x₁), …, K(x,xₙ)]   →   f(x) = Σᵢ wᵢ K(x,xᵢ)

Dense weights

Many nonzero wᵢ; typically keep all exemplars.

Sparse weights

Many wᵢ are zero; only selected exemplars influence prediction.

L2VM

L2 regularization

Convex fitting and probabilistic predictions, but typically dense weights.

L1VM

L1 regularization

Sparsity-promoting regularization. Convex fitting; kernel tuning via cross-validation.

RVM

Relevance vector machine

Bayesian ARD shrinks unneeded weights. Probabilistic and sparse, but optimization is nonconvex.

07 / Last-minute review

One-minute cheat sheet.

Platt

Fit sigmoid on held-out scores. Probability calibration is not guaranteed.

Hinge vs log

Hinge reaches exactly 0 at margin ≥ 1; log loss remains positive.

OVR / OVO

K models vs K(K−1)/2 models; ambiguity can occur with both.

C

Large C means weaker regularization (stronger error penalty).

γ

Large γ means narrower RBF kernels. Jointly tune γ and C.

RVM

ARD, sparse relevance vectors, probability predictions, nonconvex optimization.
