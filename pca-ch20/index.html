One idea behind PCA

Keep the directions that preserve the most variation

Suppose each point has two features. PCA finds a new axis that captures as much spread in the data as possible. A second axis must be perpendicular to the first.

After centering the data, keeping the first axis gives a one-dimensional summary. Points can be projected onto that axis and approximately reconstructed.

z = Wᵀ(x − μ)
x̂ = Wz + μ

μ = training-data mean; W = selected orthonormal principal directions; z = reduced coordinates; x̂ = reconstruction.

Interactive projection

Rotate the candidate axis. The cyan line is your chosen one-dimensional subspace; dots are observations. Dashed lines show what is lost during projection.

For orthonormal W, minimizing squared reconstruction error is equivalent to maximizing retained variance. The leading eigenvectors of the centered covariance matrix solve this problem. This result is introduced here as background to the assigned sections.

20.1.1 · EXAMPLES

Where PCA is useful

1 · 2D → 1D

A cloud of correlated points can be represented by its position along one line. Reconstructed points lie on that line; the perpendicular distances represent lost information.

2 · Handwritten digits

MNIST digit images have 784 pixel features, but pixel values are related. PCA can produce a two-dimensional visualization. In the book's digit-9 example, the directions appear to reflect orientation and stroke thickness.

3 · Eigenfaces

The book projects Olivetti face images (64 × 64 pixels) into a smaller subspace. Visualized components reflect major variation such as lighting and facial regions. The resulting compact representation can be used for recognition.

Examples follow Figures 20.1–20.3 in Murphy, Probabilistic Machine Learning: An Introduction.

20.1.3 · COMPUTATIONAL ISSUES

Computing PCA in practice

Covariance or correlation?

Covariance PCA is sensitive to feature scales. A variable measured in large units can dominate the principal direction. Standardizing features first makes covariance PCA equivalent to correlation-matrix PCA.

x'ⱼ = (xⱼ − μⱼ) / σⱼ

Important: standardization is often useful, not mandatory in every domain. Decide whether original scale should matter.

When D > N

A D × D covariance matrix can be expensive when there are many features and fewer examples. The N × N Gram matrix provides an alternative. The book derives how its eigenvectors can recover feature-space directions.

XXᵀ instead of XᵀX

X is centered; the relevant eigenvectors require correct normalization.

Use SVD

PCA can be computed without explicitly constructing the covariance matrix. For centered X, its right singular vectors give the PCA directions. This is often the practical choice.

X ≈ Uₗ Sₗ Vₗᵀ
Z = Uₗ Sₗ = XVₗ

With covariance defined as XᵀX/N, the eigenvalues are s²ⱼ/N.

Practical recipe

1. Split data before fitting preprocessing → 2. Center training features (optionally scale) → 3. Fit PCA/SVD on training data → 4. Transform both training and test with the same learned mean, scale, and directions → 5. Choose a dimension count that meets your goal.

Train/test preprocessing guidance is an implementation best practice extending beyond the textbook examples.

20.1.4 · CHOOSING THE NUMBER OF LATENT DIMENSIONS

How many components should we keep?

Try a component count

Illustrative eigenvalues: [5.0, 2.5, 1.0, 0.7, 0.4, 0.2, 0.1, 0.1]. This is a teaching example, not an actual dataset.

Three ways to think about L

Reconstruction error: Adding directions reduces squared reconstruction error. For PCA, it is the sum of omitted eigenvalues (using the textbook covariance normalization).

Error(L) = Σⱼ₌ₗ₊₁ᴰ λⱼ

Scree plot: Plot sorted eigenvalues, then look for an elbow where extra components add relatively little.

Explained variance: The cumulative share of total variance retained.

F(L) = (Σⱼ₌₁ᴸ λⱼ) / (Σⱼ λⱼ)

What about profile likelihood?

Section 20.1.4.3 describes a more systematic alternative to eyeballing the elbow. It considers candidate split points in the ordered eigenvalues, fitting the large-eigenvalue group and the remaining smaller-eigenvalue group with a simple statistical model, and picks the split supported best by the profile likelihood.

One subtle finding from the book: PCA reconstruction error may continue to decrease on both training and test data as L increases. Unlike a typical supervised-learning error curve, a U-shaped test reconstruction curve is not guaranteed. So an elbow, a variance-retention goal, or a model-based selection criterion is often more informative.

QUICK RECAP

What to remember for the quiz

Intuition

Principal components are orthogonal directions ordered by how much variance they explain.

Implementation

Center first, consider feature scaling, and use SVD for efficient numerical computation.

Dimension count

More components mean more retained variance and less reconstruction loss, but less compression.
